# 居家身体重组训练计划

一个为「22 岁男生、中心性肥胖（肚子大四肢瘦）」量身定制的**居家训练网站**。

- 目标：身体重组（不减体重，减肚子 + 增四肢/整体肌肉）
- 方法：高蛋白维持量饮食 + 力量训练，三分化 **A 推 / B 拉 / C 下肢**，**72 小时肌群循环**，每块肌肉每周练 2 次
- 低冲击：全部低冲击、对新手友好；重点练臀腿，兼顾全身大肌群
- 覆盖六大块：手臂（三头在推日、二头在拉日）、胸、腹（核心每天带）、背、腿、臀

## 网站结构

```
index.html          主页面（概览/周计划/三大训练日/有氧/营养/原则/答疑/打卡）
assets/css/style.css 样式（移动端优先、浅色主题）
assets/js/app.js     交互（今日推荐、动作打卡、本周日历、营养速算、导航高亮）
```
