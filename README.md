# 居家身体重组训练计划

一个为「22 岁男生、中心性肥胖（肚子大四肢瘦）」量身定制的**居家训练 + 营养备餐网站**。

- 目标：身体重组（不减体重，减肚子 + 增四肢/整体肌肉）
- 训练：高蛋白维持量饮食 + 力量训练，三分化 **A 推 / B 拉 / C 下肢**，**72 小时肌群循环**，每块肌肉每周练 2 次
- 覆盖六大块：手臂（三头在推日、二头在拉日）、胸、腹（核心每天带）、背、腿、臀
- 营养：**宏量 4 项（蛋白/脂肪/碳水/纤维）+ 微量 17 项（11 种维生素 + 6 种矿物质）**全量测算，自动拆四餐，按食材反算克数

## 功能

| 模块 | 说明 |
|---|---|
| 训练计划 | 概览、周计划、A/B/C 三训练日动作库、低冲击有氧、动作打卡（本地保存）、本周日历 |
| 营养计算 | 填身体数据 → 算维持热量/BMR → 宏量 4 项 + 四餐分配（早 25%/午 35%/晚 25%/练后 15%） |
| 食材库 | 33 种常见健身食材，宏量/维生素/矿物质三视图切换，全部 USDA 标准值（生重/干重，液体按 100ml） |
| 一键换算 | 「本餐要 50g 蛋白」→ 吃多少克鸡胸，并列出该份附带的脂肪/碳水/热量 |
| 微量营养素 | 17 项每日目标 + 实际摄入达标度进度条 + 短缺预警（给出"补 xx 食材多少克"） |
| 周备餐 | 录入本周买的食材 → 勾选每餐用哪些 → 自动分配每餐克数 + 一周采购清单 + 微量汇总 |
| 智能推荐 | 按目标生成一周采购清单（白肉为主/红肉 2–3 餐/蛋奶搭配/蔬菜轮换），一键填入食材库 |

## 数据来源

- **宏量营养素与微量营养素含量**：USDA FoodData Central 标准参考值（生重/干重计；液体按 100ml）
- **每日摄入目标**：《中国居民膳食营养素参考摄入量（2023 版）》成年男性 RNI/AI
- **长尾食材**：Open Food Facts 公益 API 联网查询（用户上传数据，仅作兜底），或手动按包装营养标签录入
